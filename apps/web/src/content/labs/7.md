## Concepts

- **Thresholding** separates pixels by intensity. Otsu's method picks one global value, while adaptive thresholding computes one per neighborhood, which handles uneven lighting.
- **Region growing** starts at seed points and adds neighbors of similar intensity.
- **Watershed** treats the image as terrain and floods it from markers, which can separate touching objects.
- **Edge-based** segmentation detects boundaries with Canny, then fills the closed contours.
- **Semantic segmentation** gives every pixel a class label using a trained deep network.
- **IoU** measures overlap with a true mask: the shared area divided by the combined area.

## Procedure

1. Apply Otsu and adaptive thresholding.
2. Grow regions from seeds, and apply watershed to separate touching objects.
3. Detect edges with Canny, close the gaps, and fill closed contours. Compare the borders with the region-based results.
4. Run a pre-trained DeepLabV3 model, and view the class of each pixel.
5. Compare the methods, using IoU where a true mask exists.

In this implementation, seeds are chosen automatically at the center of each foreground blob.
