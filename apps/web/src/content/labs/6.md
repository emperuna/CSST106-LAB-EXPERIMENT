## Concepts

- **Object detection** finds where objects are and what they are, giving a labeled box for each one.
- YOLO predicts all boxes in a single pass of the network, which makes it fast enough for video.
- **Confidence** is the model's score for a box, and the threshold decides which boxes are shown.
- Detection is scored with **precision**, **recall** and **mAP**. mAP50 counts a box as correct if it overlaps the true box by at least 50%.

## Procedure

1. Run the pre-trained `yolo11n.pt` model on images, video or a webcam.
2. Prepare a dataset with one label file per image, each line being `class_id x_center y_center width height` in normalized coordinates.
3. Describe the dataset's folders and classes in `data.yaml`.
4. Train the model on that dataset.
5. Validate it on unseen images, and analyze precision, recall and mAP.

## About this implementation

The custom model uses the public African Wildlife dataset (buffalo, elephant, rhino, zebra) instead of self-collected photos. It was trained for 30 epochs at 320 px on 120 images, rather than the sheet's 100 epochs at 640 px, because training ran on a dual-core CPU. Training is not run from this page because it takes about 18 minutes, so its saved results appear under Custom training.
