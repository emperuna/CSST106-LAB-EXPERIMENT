## Concepts

- A keypoint is a distinctive location, and its descriptor is a set of numbers summarizing the area around it. Similar descriptors suggest the same physical point.
- **SURF** finds blob-like points using box filters on an integral image, which cost the same at any size. Its descriptor has 64 values built from Haar wavelet responses.
- The **Hessian threshold** sets how strong a blob must be, so a higher value gives fewer keypoints.
- **U-SURF** skips orientation, so it only works when images are roughly upright.
- **SIFT** uses 128-value float descriptors. **ORB** uses compact binary descriptors, and is free of the patents that restricted SURF and SIFT.

## Procedure

1. Load an image in grayscale.
2. Create a SURF detector with a Hessian threshold, and detect keypoints and descriptors.
3. Draw the keypoints with their size and orientation.
4. Match descriptors between two images, keeping matches that pass Lowe's ratio test.
5. Repeat with U-SURF, SIFT and ORB on the same images, and compare.

## About this implementation

The sheet's `cv2.xfeatures2d.SURF_create` call fails on the standard OpenCV packages because SURF is patented. This project implements the published method in NumPy instead, and uses OpenCV's version on any build that includes it. Python array code is slower than compiled code, so SURF's time here says nothing about the algorithm's real speed.
