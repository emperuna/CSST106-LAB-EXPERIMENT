## Concepts

- Each 37 x 50 photo here is a point in a 1,850-dimensional space, which is expensive to work with and prone to overfitting.
- **PCA** finds the orthogonal directions of greatest variance. For faces, these look like ghostly images called **Eigenfaces**.
- A face is approximated as the mean face plus a weighted sum of Eigenfaces, so a few weights can stand in for all its pixels.
- **Whitening** rescales each component to unit variance, so that no single component dominates the SVM's distance calculations.
- PCA is fitted on the training images only, so the test set stays unseen.

## Procedure

1. Load Labeled Faces in the Wild, keeping people with at least 70 images, and split it 80/20.
2. Fit PCA with 150 components, using the randomized solver and whitening, then project both sets.
3. View the components as Eigenfaces.
4. Train an RBF SVM with balanced class weights, and evaluate it on the test set.
5. Plot cumulative explained variance, and find how many components reach 90%.
6. Inspect the faces the model got wrong.
