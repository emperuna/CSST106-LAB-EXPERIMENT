## Concepts

- A digital image is an array of numbers. A grayscale image has one value per pixel (2D), and a color image has three (3D).
- `img.shape` gives height, width and channels, in that order. Resolution is the number of pixels.
- OpenCV stores color channels as **blue, green, red**, not red, green, blue. Each 8-bit value runs from 0 to 255.
- Array indexing is row first: `img[y, x]`.

## Procedure

1. Load an image with `cv2.imread` and read its shape.
2. Convert it to grayscale and separate its color channels.
3. Read a pixel's value at chosen coordinates, change it, and compare before and after.
4. Crop a region of interest with array slicing.
5. Resize the image, and rotate it by 90 degrees.
